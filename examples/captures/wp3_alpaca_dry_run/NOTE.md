# Alpaca synthetic set — superseded by the recorded capture

This set is a synthetic empty book, kept because it exercises the
typed-absence path: no position and no order, parsed and bound
without inventing anything.

It is no longer the only Alpaca material. An owner-authorized
read-only export has since been taken, and its categorical shape --
with the substituted values clearly separated from the observed
facts -- lives in `examples/captures/wp3_alpaca_recorded/`. Read that
NOTE for what was observed and what was replaced.

What this set still proves, and the other cannot: that an account
with nothing open parses, binds and produces a directive without a
single fabricated fact.
